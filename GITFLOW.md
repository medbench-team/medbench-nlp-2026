# Правила работы

## Git-Flow:
  - У нас 2 основные ветки: `main` и `dev`
  - Каждая задача делается в отдельной ветке `feature`, которая создаётся из `dev`
  - При старте работы над задачей открывается Draft PR: `feature → dev`, задача переходит в *In progress*
  - После завершения разработки, задача переходит в статус *In review*
  - После ревью исправления пушатся в ту же `feature`-ветку, PR мёржится в `dev`, задача переходит в *Done*
  - Когда все нужные задачи в `dev` — делается PR `dev → main`, после мёржа ставится тег с версией (например, `v0.1.0`)

### Создание feature-ветки
  - На доске проекта создаётся item в статусе *draft*
  - Далее он преобразуется в issue
  - Заходим issue через проект репозитория
  - Справа, в меню блок - Development выбираем "Create branch". (по gitflow ветки вы создаёте из dev)
